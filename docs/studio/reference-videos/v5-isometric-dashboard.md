## Web build notes

- **Build-up stagger:** card scales `0 -> 1` with `cubic-bezier(.34,1.56,.64,1)` over 450 ms starting at 350 ms; chips follow at 60-90 ms intervals, each `translateY(12px) scale(.9) -> 0/1`, 350 ms `ease-out`.
- **Glass card CSS:** `background: linear-gradient(135deg, rgba(255,255,255,.75), rgba(200,225,250,.55)); backdrop-filter: blur(12px); border: 1px solid rgba(255,255,255,.6); box-shadow: 0 20px 50px -20px rgba(53,102,178,.45)` plus a thin `#3981cb` 4 px top bar.
- **Background:** `linear-gradient(160deg, #a7c3e9 0%, #95b7e3 45%, #87acdd 100%)` with a `radial-gradient(circle at 5% 0%, rgba(255,255,255,.35), transparent 30%)` corner glow.
- **Data fill:** animate bars with `scaleY` via staggered `transition-delay: i*70ms`; donut via `stroke-dashoffset` on an SVG circle (900 ms, `ease-in-out`); slider knob translates 600 ms.
- **3D swing:** put everything in a `perspective: 1200px` stage; animate the card group `rotateY(0 -> -70deg)` + `translateX(25vw)` over 600 ms `cubic-bezier(.6,0,.2,1)`; chips get `translateZ(±80px)` so they whip out with parallax.
- **Scroll-scrub:** map this whole shot to a sticky section: scroll progress 0-.35 = build-up, .35-.6 = hold + widget animations, .6-.75 = rotateY swing, .75-1 = orbs/pillars. Drive with a single GSAP timeline + ScrollTrigger `scrub: 0.6`.
- **Orbs:** CSS sphere = `radial-gradient(circle at 30% 30%, #fff8, transparent 40%), <base color>`; add `filter: drop-shadow(0 8px 12px rgba(20,60,140,.35))`. Launch each with a `translate3d` path + 250 ms trailing blur (`filter: blur(2px)` at start, 0 at rest), 100 ms stagger.
- **Pillars:** `linear-gradient(to bottom, rgba(70,150,230,.9), rgba(70,150,230,0))` cylinders with border-radius 50%/8%; grow with `scaleY` from `transform-origin: bottom` 500 ms `ease-out`, heights randomized 0.6-1.4x.
- **Camera tilt to top-down:** animate the whole stage `rotateX(0 -> 60deg)` with `translateY(-30vh)` over 600 ms `ease-in-out`; fade the background to `#7ea5d9` at the end.
- **Particles:** 30-40 absolutely-positioned 3-4 px circles `#7fe6f2` at 60% opacity, slow `translateY` float, 6-10 s loops; respect `prefers-reduced-motion`.
- **Reduced-motion fallback:** show the final pillar frame as a static image.
