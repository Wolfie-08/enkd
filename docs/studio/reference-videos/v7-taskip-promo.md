**Style summary:** Glassy, high-key 3D UI motion design. Every transition is a physical move (page curl, camera push through a UI, tunnel flight), synced to the bass pulse. Typography is Inter-style neutral sans in the UI and a bold grotesk for big wordmarks.

## Web build notes

- **Paper-curl reveal (page peel):** build with a two-layer clip: the top "page" is a `div` with `clip-path` moving diagonally and a pseudo-element gradient (`linear-gradient(135deg, #fff, #dcdcf5)`) plus `box-shadow`; or use CSS `mask` with `radial-gradient` corner. Duration 600-800 ms `cubic-bezier(.6,0,.2,1)`. Use it as the standard scene transition instead of dissolves.
- **Glass UI panel stack (Email Analytics style):** `perspective:1600px; transform: rotateX(18deg) rotateY(-22deg) rotateZ(2deg)`; layer sheets with `translateZ(-N*14px)` and lilac edges (`box-shadow: 0 0 0 1px rgba(150,120,255,.5)`), then `translateZ` collapses to 0 as the menu "unfolds" (`stagger .05`).
- **Mint hero background:** `background: linear-gradient(115deg,#c1ffef 0%,#eafffa 45%,#ffffff 70%,#c1ffef 100%)` with 3 rotated blurred white diagonal stripes (`filter: blur(40px); transform: rotate(-30deg)`), drifting 20 s linear.
- **Feature icon sequence ("Integrated Scheduling" / "Getting Paid"):** one shared circle element morphs (cube to calendar to $ to check) using `scale` overshoot 350 ms `back.out(2)`, caption fades with `letter-spacing: .3em -> 0` + `blur(6px)->0`, 400 ms.
- **Orbit / floating-label cloud:** absolutely position 9-10 glass chips at random `z` from -400 to 200 px inside a `perspective:1000px` stage; animate `translate3d` diagonally over 1.2-2 s with different speeds (parallax = z-dependent), `backdrop-filter: blur(8px)`, `background: rgba(255,255,255,.55)`. Tasks/Proposal/Teams/Projects/Invoices/Documents/Meetings/Discussions/Forms is the exact vocabulary.
- **Logo pulse:** sphere `radial-gradient(circle at 50% 20%, #14d8ff, #0463ff 55%, #7a5cff 100%)` with two expanding ripple rings (`scale 1 -> 2`, `opacity .6 -> 0`, 1.6 s, delay .4 s, infinite).
- **TASKIP letter cascade:** split into spans; per letter `rotate(-20deg) translateY(30px) opacity 0` to identity, `back.out(2.4)`, `stagger .06`, total 700 ms.
- **Kinetic word ("SCHEDULING"):** letters slide from `x:-120%` with `elastic.out(1,.55)`, last two letters get an SVG `feTurbulence` displacement briefly for the blob-wobble.
- **Cursor click scene:** flat SVG cursor animates `x/y` along a bezier 450 ms `power3.out`, then `scale .88 -> 1` 90 ms + button `filter: brightness(1.25)` flash; card `rotate(45deg) translate` exit 500 ms `power2.in`.
- **Scroll structure:** treat each shot as a section pinned for 100-150 vh; bass hits become scroll-trigger snap points. Keep neon tunnel as a canvas or pre-rendered 1.2 s WebM (it is too heavy for CSS).
- **Palette tokens:** `--mint:#c1ffef; --violet:#5900ff; --cyan:#14d8ff; --cobalt:#0463ff; --pink:#ffc4f4; --lav:#d499fd; --yellow:#feec6e; --magenta:#f47dff`.
